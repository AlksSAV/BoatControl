Версия: 0.1
Плата: Seeed Studio XIAO ESP32-C6
Связанный документ: [SPEC.md](SPEC.md) — логика, карты, пороги.

## 1. Функциональная схема

```
                     ┌──────────────────────────┐
  Батарея ──► РУБИЛЬНИК ──► ПРЕДОХРАНИТЕЛЬ ──┬──► ESC ──► мотор
   (силовая)   (физ.)        (F, [УТОЧНИТЬ])  │      │
                                              │      └──► BEC 5–6 В ──┐
                                              │        (или отдельный  │
                                              │         UBEC)          │
                                              │                        │
   ┌──────────────────────────────────────────┴────────────────────────┴───┐
   │  ЛОГИКА (3.3 В, общий GND с силовой)                                  │
   │                                                                       │
   │  Стик X (10 кОм) ──► RC-фильтр ──► D0/GPIO0  (ADC1_CH0)   руль        │
   │  Стик Y (10 кОм) ──► RC-фильтр ──► D1/GPIO1  (ADC1_CH1)   газ         │
   │  Кнопка ─────────────────────────► D3/GPIO21 (pull-up, низ активн.)   │
   │  LED1 (готов) ◄── резистор ─────── D6/GPIO16                          │
   │  LED2 (круиз) ◄── резистор ─────── D7/GPIO17                          │
   │  D4/GPIO22 ──► сигнал ESC   (50 Гц, 1000–2000 мкс)                    │
   │  D5/GPIO23 ──► сигнал сервы (50 Гц, 1000–2000 мкс)                    │
   │  D8/GPIO19, D9/GPIO20 ──► UART отладки (опционально, USB-Serial/JTAG  │
   │                            на плате используется по умолчанию)         │
   └───────────────────────────────────────────────────────────────────────┘
```

## 2. Распиновка XIAO ESP32-C6

Соответствие pad → GPIO (проверено по board definition):

| Pad | GPIO | Назначение в проекте | Почему этот пин |
|---|---|---|---|
| **D0 / A0** | GPIO0 | **Стик X — руль (ADC)** | ADC1_CH0; один из трёх выведенных аналоговых |
| **D1 / A1** | GPIO1 | **Стик Y — газ (ADC)** | ADC1_CH1 |
| **D2 / A2** | GPIO2 | Резерв аналоговый | ADC1_CH2; не задействован в v0.1 |
| **D3** | GPIO21 | **Кнопка круиза** | свободный digital, подтяжка внутри |
| **D4** | GPIO22 | **PWM → ESC** | свободный digital |
| **D5** | GPIO23 | **PWM → серва** | свободный digital |
| **D6** | GPIO16 | LED «готовность» | свободный digital (в ряде сборок = UART0 TX, проверять) |
| **D7** | GPIO17 | LED «круиз» | свободный digital (в ряде сборок = UART0 RX) |
| **D8** | GPIO19 | UART TX (отладка) | свободный |
| **D9** | GPIO20 | UART RX (отладка) | свободный |
| **D10** | GPIO18 | Резерв | свободный |
| 5V | — | вход питания логики / питание LED от 5 В | |
| 3V3 | — | **питание потенциометров стика** | тот же узел, что и опора АЦП |
| GND | — | общий с силовой цепью **обязательно** | |

### 2.1 Пины, которые НЕ трогать

| GPIO | Причина |
|---|---|
| GPIO3 | enable встроенного RF-коммутатора (активный низ) — занято платой |
| GPIO14 | select антенны RF-коммутатора — занято платой |
| GPIO15 | бортовой LED (active-low) — используем только как индикатор |
| GPIO12, GPIO13 | USB D−/D+ (USB Serial/JTAG) — при переназначении пропадает прошивка по USB |
| GPIO6…GPIO11 | подключены к внутренней SPI-flash — **не использовать** |
| GPIO2 | ADC1_CH2 + RTC wake-up — резерв, в v0.1 не нагружать |

**Вывод по аналогу:** из ADC1 (GPIO0…GPIO6) на колодки выведены только GPIO0, GPIO1, GPIO2. Под две оси стика — ровно впритык, GPIO2 в резерве. Это единственный узел, где запас мал: если когда-нибудь понадобится третья аналоговая ось (например, отдельный потенциометр трима), она возможна только на GPIO2.

## 3. Вход стика: схема на каждую ось

```
        3V3 ────┬──────────────────────┐
                │                      │
            R1 1кОм                C1 100 нК (X7R, 0402/0603)
                │                      │
   бегунок ─────┴──────► ADC pin       │
   стика  ────┬─────────────────────────┘
              │
             GND
```

- **Питание потенциометров — от 3V3**, не от 5 В. Иначе верхняя часть диапазона обрезается, а «нейтраль 1500 мкс» уплывает вместе с просадкой батареи. 10 кОм от 3.3 В → 0.33 мА на ось, током пренебрегаем.
- **R1 1кОм + C1 100 нК** — фильтр нижних частот (f ≈ 1.6 кГц): подавляет наводки от мотора/ESC и ВЧ-шум. Ставим **у платы**, не у стика.
- При длине проводов от стика **> 1 м** — экранированный кабель, экран в GND логики в одном конце (у платы), и дополнительно C2 1 мкФ у ADC-пина.
- **TVS на аналоговые входы не ставим** (их ёмкость портит точность); вместо этого следим, чтобы на стик физически не попал 5 В или силовое напряжение — это вопрос монтажа разъёмов (см. п. 6).

### 3.1 Точность АЦП

- АЦП ESP32-C6 шумит и нелинеен в нижней/верхней частях диапазона — это норма, а не дефект.
- Рабочий диапазон объявляем **`ADC_VALID_MIN = 100 … ADC_VALID_MAX = 3995`**; в «нехороших» концах детектируем обрыв/КЗ, а не пытаемся считать.
- Реальная линейность и разброс нулей проверяются **[СТЕНД]**: крутим стик и пишем таблицу raw → импульс. Если нелинейность мешает — решаем кусочной линеаризацией в `config.h`, не «на слух».

## 4. Питание

### 4.1 Цепи

| Цепь | Источник | Ток | Комментарий |
|---|---|---|---|
| Мотор | батарея через рубильник + предохранитель + ESC | **[УТОЧНИТЬ]** — по паспорту мотора/ESC | силовая, мимо платы |
| Логика (XIAO) | BEC 5 В → пин 5V платы | десятки мА **[СТЕНД]** | линейный регулятор платы греется при 5 В входе — проверить температурой |
| Серва руля | **отдельный UBEC 5–6 В**, не 3V3 платы | пик при упоре в механику — **[УТОЧНИТЬ]** по модели сервы | серва без концевиков **будет** держать момент на упоре, это главный ток |
| Потенциометры стика | 3V3 платы | ~0.7 мА суммарно | см. п. 3 |

### 4.2 Правила, обязательные при монтаже

1. **Общий GND силовой и логики — одна точка.** Заземляем минус батареи и минус UBEC вместе в одной точке (звезда), иначе по «земле» потечёт ток мотора и аналог стика поплывёт.
2. **Серву не питать от BEC внутри ESC, если он слаботочный** (обычно 3–5 В/до 1 А) — при упоре руля в механику просадка сажает и ESC-логику, и плату.
3. **Физический рубильник** в плюсовом проводе батареи — доступный без инструментов, с фиксацией «выкл». Электроника его не заменяет (см. SPEC п. 6).
4. **Предохранитель** на силовом входе — номинал **[УТОЧНИТЬ]**, подбирается по току мотора (обычно 1.25–1.5 × рабочий ток).
5. **Конденсатор по входу питания логики** 220–470 мкФ + 100 нК рядом с платой — буфер просадок от сервы.
6. Провод ESC→серва→плата: сигнальные провода **не в одном жгуте** с силовыми мотора.

### 4.3 Уровни логики (риск, проверить)

Выход платы — 3.3 В. Большинство серво/ESC принимают high ≥ ~2.0–2.5 В, но не все.

- **[СТЕНД]**: осциллограф/логика — видит ли ESC 1000 и 2000 мкс именно как крайние положения. Если полный ход не достигается — нужен level shifter (TXB0104) или однотранзисторный формирователь на 5 В.
- Если ESC требует именно 5 В-логику — ставим сдвигатель **до** финального выбора GPIO (D4/D5), а не перекидываем пины.

## 5. Выходы ESC и сервы

- Сигнал: 50 Гц, импульс 1000–2000 мкс, нейтраль 1500 (см. SPEC п. 4).
- Реализация: **LEDC или RMT — решение в PLATFORM.md/коде**, на железе это просто два GPIO. Требование одно: длительность импульса не должна «прыгать» при загрузке CPU и при работе питания.
- Подключение по стандарту RC-серво: **сигнал → D4/D5, + → BEC/UBEC, − → общий GND**.
- **Никогда не оставляем вход ESC/сервы «висящим»** — при инициализации сразу 1500 мкс (SPEC п. 6.1).

## 6. Механика, корпус, среда

| Требование | Решение |
|---|---|
| Влага | плата в герметичном отсеке; разъёмы с фиксацией; покрытие конформным лаком (не на разъёмах) |
| Конденсат | отверстие-дренаж + силикагель в отсеке; кабельные вводы вниз |
| Вибрация | плата на стойках с прокладками; провода с разгрузкой (клеммники/стяжки), пайка бегунков стика — без натяжения |
| Джойстик | панельный, с самовозвратом обеих осей (уже есть), пылевлагозащита не ниже IP54 |
| Кнопка круиза | фиксация нажатия **не** требуется; лучше — с чётким тактильным щелчком; location: в пределах досягаемости руки, держащей стик |
| Индикация | светодиоды видны при дневном свете на воде → яркие, с матовым рассеивателем; LED «круиз» — отдельный цвет (обычно зелёный/синий), чтобы не путать с «готов» |
| Рубильник | у места оператора, крупный, с защитой от случайного включения |
| Винт | **до первого спуска на воду — снят**; все проверки SPEC п. 9 делаются на стенке |

## 8. Что нужно от вас (аппаратные ответы)

Влияют на точные значения, но не блокируют каркас:

1. **Модель ESC** — рабочий ток, наличие/ток встроенного BEC, требования к логике (3.3 В / 5 В), нейтральная зона.
2. **Модель сервы** — ток, рабочее напряжение (4.8 В / 6.0 В / 5 В), момент на упоре.
3. **Модель джойстика** — закон изменения (линейный?), есть ли встроенная кнопка, тип выводов (провода/разъём).
4. **Батарея** — напряжение и ёмкость (от этого номинал предохранителя и выбор UBEC).
5. **Длина проводов** от стика до платы (влияет на п. 3).

С 1–5 можно вернуться позже: каркас, спецификация логика и код от них не зависят — они уходят в `config.h`.
