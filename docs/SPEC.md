# BoatControl — спецификация прошивки (SPEC)

Версия: 0.1 (концепция согласована, значения порогов требуют подтверждения на стенде)
Платформа: Seeed Studio XIAO ESP32-C6
Статус: документ-основание. Код пишется только после принятия этого файла.

---

## 1. Область

### 1.1 Что входит

- Управление мотором через ESC по PWM (стандарт RC-сервопривода, 50 Гц, 1000–2000 мкс).
- Управление рулевой сервой по PWM (50 Гц, 1000–2000 мкс).
- Два входа от аналогового джойстика с самовозвратом обеих осей (потенциометры 10 кОм).
- Одна кнопка режимов круиза (только включение/выключение).
- Индикация режима и ошибок светодиодами.
- Автономная работа: устройства не опрашивают прошивку, внешней связи нет.

### 1.2 Что НЕ входит (осознанно исключено)

- RC-приёмник — убран полностью, второго источника управления нет.
- GPS, компас, телеметрия, автономный курс — не будет.
- Мониторинг просадки напряжения батареи и ограничение по нему — не будет (пересмотр при необходимости).
- Обратная связь от сервы, энкодеры, концевые выключатели — отсутствуют.
- Второй пост управления — нет, одно рабочее место.

### 1.3 Следствия из 1.2

Единственный орган управления и единственный «мозг» — одна плата. Отказ платы означает потерю управления. Это компенсируется **физическим рубильником в силовой цепи** (см. HARDWARE.md) и тем, что штатное состояние платы при отказе — «газ в стоп, руль в центр».

### 2.1 Ключевые ограничения из таблицы выше

1. **Аналоговые входы стика — только D0 (GPIO0) и D1 (GPIO1).** Из ADC1 (GPIO0…GPIO6) на колодки XIAO выведены лишь GPIO0, GPIO1, GPIO2, причём GPIO3 занят под переключение антенны. D2 (GPIO2) остаётся резервом под третью аналоговую ось.
2. **GPIO14 и GPIO15 заняты платой** (антенна и LED). Внешние светодиоды вешаем на свободные pads.
3. Радио (Wi-Fi/BLE/802.15.4) **не инициализируем**. Джиттер выходного сигнала от радионагрузки — основной риск для RC-тайминга; без радио он снят по определению.

## 4. Сигнальные карты

### 4.1 Общий формат выхода

Обе линии — **50 Гц**, кадр 20 000 мкс, активный импульс **1000…2000 мкс**.

### 4.2 Карта газа (ось Y, реверс есть)

```
        стик Y                импульс ESC        направление
   от себя до упора   →      1000 мкс          полный вперёд
   от себя (центр→край) →    1000…1500 мкс     вперёд 100…0 %
   центр (покой)       →      1500 мкс          СТОП
   на себя (центр→край) →     1500…2000 мкс     назад 0…100 %
   на себя до упора    →      2000 мкс          полный назад
```

**Полярность оси подтверждается на стенде.** Если фактически «от себя» даёт реверс, применяется инверсия оси (`THR_INVERT = 1`) — см. п. 7.

Формула:

```
raw      = ADC(Y)                                   // 0..4095
center   = thr_center (авто-тарировка, п. 5.2)
dead     = |raw - center| <= THR_DEADBAND_ADC       → газ 0 (1500 мкс)
mag      = (|raw - center| - THR_DEADBAND_ADC) / (THR_SPAN_ADC - THR_DEADBAND_ADC)   → clamp 0..1
pulse    = 1500 + sign * mag * 500                  // sign: -1 вперёд, +1 назад
```

### 4.3 Карта руля (ось X)

```
        стик X                импульс сервы
   до упора влево       →      1000 мкс
   центр (покой)        →      1500 мкс
   до упора вправо      →      2000 мкс
```

Экспонента у центра (руль не должен «дёргаться» на мелких отклонениях):

```
mag = |raw - center| / (X_SPAN_ADC - X_DEADBAND_ADC), clamp 0..1
mag = mag^X_EXPONENT                                 // X_EXPONENT = 1.4
pulse = 1500 + sign * mag * X_RANGE                  // X_RANGE = 500 → 1000..2000
```

Ограничение хода руля: **программное** (константы `STB_PULSE_MIN/MAX`), механических концевиков нет. При сборке выставляются механические упоры тяги, а программный диапазон делается чуть уже упоров, чтобы серва не держала момент на упоре.

### 4.4 Мёртвые зоны

- Вокруг нейтрали газа — с **обеих** сторон: `THR_DEADBAND_ADC`.
- Вокруг центра руля — с обеих сторон: `X_DEADBAND_ADC`.
- Ширина подбирается на стенде: под шум АЦП + фактическую нейтральную зону ESC.

## 5. Поведение

### 5.1 Цикл

- Период: **20 мс (50 Гц)**. Один такт = чтение АЦП → фильтрация → обработка состояний → расчёт импульсов → запись на выходы → кормёжка watchdog.
- АЦП: oversampling (не менее 16 отсчётов на канал за такт) + скользящее среднее.
- Выходы обновляются каждый такт, в конце такта — кормёжка сторожевого таймера.

### 5.2 Стартовая последовательность

```
t=0        подача питания. Выходы: 1500 / 1500. Круиз выключен.
t=0..0.5c  пауза, ничего не читаем (стабилизация питания, RC-фильтров)
t=0.5..1.0s тарировка нуля: 50 выборок каждой оси при стике в покое → center_X, center_Y
           проверка допуска (п. 5.3) и проверка валидности АЦП
t=1.0s     арминг выполнен → READY. Индикация: LED «готов» постоянно.
```

- **Если при включении стик отклонён** — тарировка даст неверный центр, что ловится допуском (п. 5.3) и уводит в FAULT. Самовозврат стика делает это редкостью, но проверка обязательна.
- Пауза 1 с после включения — требование пользователя (ESC готов через 1 с).

### 5.3 Допуск тарировки

Авто-тарировка принимается, если:

```
|center - 2048| <= CAL_MAX_OFFSET_ADC      // смещение нуля от «идеального» центра
CAL_MIN_ADC <= center <= CAL_MAX_ADC       // АЦП не в обрыве и не в потолок
разброс выборок (max-min) <= CAL_MAX_NOISE_ADC   // стик действительно в покое
```

Не выполнено любое из условий → **FAULT: ошибка калибровки**, выходы в 1500/1500, индикация — быстрое мигание LED ошибки. Выход из FAULT только перезапитанием (защита от «само прошло»).

### 5.4 Ограничение скорости набора газа

Рывок газа = удар по редуктору, валу и скачок тока; для ESC это ещё и риск отказа.

```
THR_RATE_UP      : не более N % за 100 мс при наборе (вперёд и назад отдельно)
THR_RATE_DOWN    : быстрее разрешено (сброс газа в ноль не вредит механике)
THR_ZERO_PASS_MS : пауза в 1500 мкс при смене знака (вперёд ↔ назад)
```

- **Смена направления требует прохода через нейтраль.** Из «+60 %» нельзя мгновенно уйти в «−30 %»: сначала выход доходит до 1500, держится `THR_ZERO_PASS_MS`, затем разрешается противоположный знак.
- Значения подбираются на стенде (п. 9), по умолчанию `THR_RATE_UP = 8 %/100 мс`, `THR_ZERO_PASS_MS = 250 мс`.

### 5.5 Круиз (только вкл/выкл)

**Включение** (front по кнопке, debounce 25 мс):

```
разрешено, если: состояние == DRIVE
                 и активный газ > 0 (стик вне мёртвой зоны)
                 и знак газа == «вперёд» (реверс не фиксируем)
                 и |выходного импульса| в допустимых пределах
при включении запоминается: ФАКТИЧЕСКИ ВЫДАВАЕМОЕ значение импульса (не позиция стика)
```

Причина брать выдаваемое значение, а не позицию стика: из-за rate limit и фильтра эти величины различаются, и захват позиции дал бы щелчок оборотов в момент включения.

**В активном круизе:**

- Ось Y **игнорируется полностью** (согласовано: никакой override).
- Ось X работает штатно — руль доступен.
- Задний ход доступен только после выключения круиза кнопкой. Это следствие простого правила «вкл/выкл» и оно безопасно, но требует привычки: **длинное нажатие кнопки = принудительный сброс круиза** (2000 мс) — на случай, когда нужно срочно вернуть управление газом.

**Выключение** (front по кнопке, или длинное нажатие, или уход в FAULT):

- Плавный возврат (`CRUISE_RAMP_MS = 800 мс`) от зафиксированного значения к текущей позиции стика, с соблюдением п. 5.4 (включая проход через нейтраль, если стик в реверсе).
- Никаких скачков: выход продолжает двигаться по тем же правилам ограничения скорости.

**Отказ оси Y при активном круизе:** круиз **не сбрасывается** — держим зафиксированное значение (стик самовозвратный, его обрыв дал бы 0 или потолок, и это не должно ронять газ). Но если **само зафиксированное значение** стало недостоверным (выход за пределы, watchdog счёта) → газ 1500, круиз сброшен, FAULT.

### 5.6 Состояния

```
BOOT ──► CALIBRATE ──► READY ──► DRIVE ──► CRUISE
              │            │        │          │
              └────────────┴────────┴──────────┴──► FAULT  (только перезапитание)
```

| Состояние | Выход газа | Выход руля | LED готовность | LED круиз |
|---|---|---|---|---|
| BOOT | 1500 | 1500 | выкл | выкл |
| CALIBRATE | 1500 | 1500 | медленное мигание | выкл |
| READY | 1500 | 1500 | вкл | выкл |
| DRIVE | по стике (п. 4.2) | по стике (п. 4.3) | вкл | выкл |
| CRUISE | зафиксировано | по стике | вкл | вкл |
| FAULT | 1500 | 1500 | быстрое мигание | выкл |

Переход READY → DRIVE: при выводе газа за пределы мёртвой зоны. Возврат DRIVE → READY: при возврате в мёртвую зону.

## 6. Fail-safe

Приоритет: **безопасность людей важнее продолжения движения.** Любая недостоверность → «стоп, руль в центр».

| Отказ | Детекция | Действие |
|---|---|---|
| Обрыв/КЗ оси стика | значение вне `ADC_VALID_MIN..MAX` или вне допустимого хода | в READY/DRIVE: газ 1500, руль 1500 → FAULT. В CRUISE: см. п. 5.5 |
| Залипание/дрейф стика | разброс выборок не сходится при «покое» | FAULT на тарировке; в DRIVE — не влияет (стик там активен) |
| Шум АЦП выше нормы | скользящая дисперсия > `ADC_NOISE_MAX` | газ 1500, повторная тарировка → при сохранении FAULT |
| Просрочка такта цикла | watchdog (SWDT) не покормлен | HW reset → BOOT |
| Залипание кнопки круиза | удержание > `BTN_STUCK_MS` без смены состояния | круиз сбросить, FAULT |
| Недостоверность зафиксированного круиза | значение вне пределов | газ 1500, сброс круиза, FAULT |
| Отказ платы / потеря питания | — | ESC по своей fail-safe → стоп; физический рубильник у оператора |

### 6.1 Правила, обязательные при реализации

1. Значение по умолчанию при инициализации периферии — **1500 мкс на обеих линиях**, до первого такта цикла.
2. Выходы никогда не переводятся в Hi-Z (висящий вход ESC = непредсказуемое поведение).
3. Состояние круиза **не восстанавливается** после перезагрузки (старт всегда с круиза выключенного).
4. FAULT не сбрасывается «само»: только перезапитание. Исключение — шум АЦП (п. 6), где разрешена одна повторная тарировка.

## 8. Индикация

Только светодиоды, без звука и дисплея (согласовано).

| Индикатор | Пин | Показывает |
|---|---|---|
| Готовность/состояние | D6 (GPIO16) | выкл = BOOT; медленное мигание = CALIBRATE; вкл = READY/DRIVE; быстрое мигание = FAULT |
| Круиз | D7 (GPIO17) | вкл = круиз активен; выкл = не активен |
| Бортовой LED | GPIO15 (active-low) | дублирует «готовность» — виден при открытой крышке поста |

Отказ тарировки должен быть **отличим** от других FAULT (например, двойными вспышками), иначе на воде мы получим «просто мигает и не едет» без понимания причины.

## 9. Приёмочные проверки на стенде (до воды)

Проводятся **с снятым винтом** или в ванне, мотор на стенке.

1. **Полярность осей.** Отклонить Y «от себя» → мотор вперёд; X вправо → руль вправо. Не совпало — выставить `THR_INVERT` / `STB_INVERT`.
2. **Фактическая нейтральная зона ESC.** Медленно поднимать газ от 1500 и фиксировать импульс, при котором ESC начинает вращаться → в `THR_DEADBAND_ADC`. Если зона ESC шире нашей — расширяем свою.
3. **Смена направления.** Полный вперёд → полный назад (а) без паузы и (б) с `THR_ZERO_PASS_MS`. Смотрим: ошибка ESC, щелчок, отказ. Подтверждаем/уменьшаем паузу.
4. **Реакция на rate limit.** Сравнить поведение при `THR_RATE_UP_PCT` = 4 / 8 / 15. Выбрать по току и комфорту.
5. **Тарировка на холодную и на прогретую** (30+ мин работы). Записать смещение `center_Y`. Если дрейфует ближе к допуску — усилить фильтрацию или сократить допуск и требовать повторной тарировки.
6. **Шум АЦП.** Осциллограф/лог: разброс при покое и при работе BEC/мотора. Подтвердить номиналы RC-фильтра (100 нК + 1 кОм).
7. **Программные упоры руля.** Выставить механические упоры тяги, затем `STB_PULSE_MIN/MAX` чуть внутри них. Проверить, что серва не гудит на упоре.
8. **Кнопка.** Short/long, debounce, залипание. Проверить, что длинное нажатие реально сбрасывает круиз.
9. **Круиз.** Вкл на 30 % → отпустить стик → удержание. Выкл → плавный возврат. Вкл, затем попытка реверса стиком → газа назад нет. Длинное нажатие → сброс.
10. **Отказы.** Выдернуть провод оси Y в DRIVE и в CRUISE → свериться с п. 6. Замкнуть на землю → то же.
11. **Watchdog.** Зациклить задачу вручную (тест-флаг) → должен быть сброс и старт с BOOT.
