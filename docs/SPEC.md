# SPEC

Плата: Seeed Studio XIAO ESP32-C6. Версия 0.1. Пороги подтверняются на стенде.

## 1. Состав

- ESC (мотор) по PWM 50 Гц, 1000–2000 мкс, реверс есть.
- Серва руля PWM 50 Гц, 1000–2000 мкс, без обратной связи и концевиков.
- Джойстик: 2 оси по 10 кОм, самовозврат обеих.
- Кнопка круиза: только вкл/выкл.
- Индикация: светодиоды.
- Один пост управления, внешней связи нет, питание через BEC.

## 2. Пины

| Функция | Pad | GPIO |
|---|---|---|
| Стик X (руль), ADC | D0 | 0 |
| Стик Y (газ), ADC | D1 | 1 |
| Кнопка круиза | D3 | 21 |
| PWM → ESC | D4 | 22 |
| PWM → серва | D5 | 23 |
| LED готовность | D6 | 16 |
| LED круиз | D7 | 17 |
| Бортовой LED | — | 15 (active-low) |

Не трогать: GPIO3/14 (антенна платы), GPIO12/13 (USB), GPIO6–11 (SPI flash).
Аналог выведен только на GPIO0/1/2 (D0/D1/D2), ADC1.

## 3. Карты

Газ (ось Y), нейтраль 1500 = стоп:

- стик от себя → 1500 → 1000 = вперёд 0–100 %
- стик на себя → 1500 → 2000 = назад 0–100 %
- мёртвая зона с обеих сторон от 1500
- смена знака требует прохода через нейтраль + пауза
- набор газа ограничен по скорости, сброс быстрее
- полярность оси подтверждается на стенде (инверсия — константа)

Руль (ось X): влево 1000, центр 1500, вправо 2000, мёртвая зона у центра.
Программные упоры STB_PULSE_MIN/MAX ставятся чуть внутри механических.

## 4. Состояния

BOOT → CALIBRATE → READY → DRIVE ⇄ CRUISE, любой сбой → FAULT (сброс только перезапитанием).

| Состояние | Газ | Руль | LED готовность | LED круиз |
|---|---|---|---|---|
| BOOT / CALIBRATE | 1500 | 1500 | выкл / медл. мигание | выкл |
| READY | 1500 | 1500 | вкл | выкл |
| DRIVE | по стике | по стике | вкл | выкл |
| CRUISE | зафиксирован | по стике | вкл | вкл |
| FAULT | 1500 | 1500 | быстро мигает | выкл |

## 5. Арминг и тарировка

1. t=0: выходы 1500/1500, круиз выключен.
2. Пауза 1 с (требование: ESC готов через 1 с после включения).
3. Авто-тарировка нуля обеих осей (стик в покое), проверка допуска смещения, разброса и валидности АЦП.
4. Допуск не пройден → FAULT, индикация отличается от прочих ошибок.

Круиз после перезагрузки всегда выключен.

## 6. Круиз

- Включение коротким нажатием: только в DRIVE, только вперёд, газ выше порога.
- Фиксируется **фактически выдаваемое** значение, не позиция стика.
- Активном круизе ось Y игнорируется полностью, руль работает.
- Выключение коротким нажатием → плавный возврат к позиции стика с соблюдением п. 3.
- Длинное нажатие (2 с) → принудительный сброс круиза.
- Обрыв оси Y в круизе не роняет газ; недостоверность зафиксированного значения → 1500 + FAULT.

## 7. Fail-safe

| Отказ | Действие |
|---|---|
| Обрыв/КЗ оси в READY/DRIVE | 1500/1500, FAULT |
| Обрыв оси Y в CRUISE | круиз держит |
| Недостоверный круиз | 1500, сброс, FAULT |
| Шум АЦП выше порога | 1500, повторная тарировка, иначе FAULT |
| Залипание кнопки | сброс круиза, FAULT |
| Просрочка такта (watchdog) | сброс платы → BOOT |

Выходы никогда не в Hi-Z. При инициализации сразу 1500 на обеих линиях.
Физический рубильник в силовой цепи обязателен, электроника его не заменяет.

## 8. Параметры (все — в `config.h`)

Период цикла 20 мс, oversampling АЦП, пауза арминга 1000 мс, нейтраль 1500, ход 500,
мёртвые зоны газа и руля, полные ходы осей, инверсии осей, rate up/down, пауза смены знака,
порог включения круиза, время возврата из круиза, debounce/long/stuck кнопки,
допуски тарировки (смещение, разброс), границы валидности АЦП, порог шума,
программные упоры руля, частоты мигания LED, таймаут watchdog.

## 9. Стенд (винт снят)

1. Полярность осей.
2. Фактическая нейтральная зона ESC → подогнать свою.
3. Смена направления: с паузой и без.
4. Подбор rate limit по току.
5. Смещение нуля на холодную и прогретую.
6. Шум АЦП при работающем моторе.
7. Программные упоры руля против механических.
8. Кнопка: short/long/debounce/залипание.
9. Круиз: включение, удержание, возврат, попытка реверса, длинное нажатие.
10. Выдернуть/замкнуть ось Y в DRIVE и в CRUISE.
11. Сброс по watchdog.

## 10. Не хватает данных

Модели ESC, сервы, джойстика, батареи; длина проводов стика; ток BEC; уровень логики 3.3 В или 5 В.
Всё это уходит в `config.h` и схему, на логику не влияет.
